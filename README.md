# 三合棋牌 · 八雀 / 斗仙 / 三国

单机离线棋牌合集，纯前端（一个 `index.html`，无框架、无网络请求），
针对 iPhone Safari 设计，可「添加到主屏幕」当成 App 使用。

## 装到 iPhone 上（推荐：直接用线上地址）

已发布到 GitHub Pages：**https://wugekelvin04-sys.github.io/happy/**

1. iPhone 用 **Safari** 打开上面的地址（必须是 Safari，Chrome 不能添加 PWA）；
2. 点底部「分享」→「添加到主屏幕」→ 添加；
3. 首次打开后 Service Worker 会缓存全部资源，之后**断网也能玩**。

> **横屏玩**：三个牌桌都是横屏围桌布局（和官方一致）。竖着拿会提示「请横屏使用」，
> 把手机转过来即可；记得关掉系统的「竖屏方向锁定」。

更新方式：改完代码 `git push` 即可，GitHub Pages 自动重新发布；
手机上下次联网打开时会拉到新版本（Service Worker 缓存名 `sanhe-qipai-v1`，
改动较大时把 `sw.js` 里的 `CACHE` 版本号一起改掉，能强制刷新缓存）。

## 本地调试

也可以在 Mac 上起一个静态服务器（局域网内 iPhone 同样能装）：

```bash
cd /Users/bytedance/app/happy
./serve.sh          # 默认 8080 端口，可传参 ./serve.sh 9000
```

终端会打印一个局域网地址（例如 `http://192.168.1.23:8080/`），
iPhone 与 Mac 连同一个 Wi-Fi 即可访问。

> 注意：本地调试时 Service Worker 会缓存旧版页面。改完代码看不到变化，
> 在浏览器控制台执行一次
> `for(const r of await navigator.serviceWorker.getRegistrations()) await r.unregister(); for(const k of await caches.keys()) await caches.delete(k);`
> 然后刷新。

## 功能

- **三款玩法**（规则全部按腾讯《欢乐斗地主》官方公告 + 实机录像实现，见 `RULES.md`）：
  - **百变八雀牌**：84 张牌（含 12 张 8 / 4 癞子 / 4 机会牌）、4 人摸打、8 张成胡；
    20 种番型、自摸 ×3 / 地胡 ×16 / 海底捞月 ×4 / 硬气结算两次，按牌面分数结算，胡牌不离场。
  - **斗仙牌**：52 张、4 人独斗、凡(2)灵(3)仙(5)三界布阵、4 回合；飞升、弃牌补牌、
    灵力值 =（点数 × 牌型倍率 + 牌型值）× 回合倍率（灵气复苏 1/2/2/3）、全胜与得证大道。
  - **三国牌**：52 张、5 人各自为战、魏(3)蜀(0)吴(2)公共牌、4 轮；第 1 名赢所有人，
    名次倍率 32/24/12/4，暴击 / 杀牌加倍。
- **模拟匹配**：进桌前有匹配动画，人机逐个入座，可「换一桌」重新匹配。
- **人机身份**：每个人机随机昵称（三套昵称库组合）、随机头像、随机携带欢乐豆，偶尔会匹配到土豪。
- **昵称**：大厅点自己的名字（或「我的」）可以直接改，改完固定不变。
- **欢乐豆系统**：初始 1,000,000 豆，输赢实时结算并持久化（localStorage）。斗仙牌底分 150（与官方新手场一致）。
- **模拟充值**：6 档商城礼包 + 破产补助，**纯本地数字，不涉及任何真实支付/账号**。
- **横屏围桌**：玩家围坐一圈，中间是公共出牌区；出牌 / 摸牌 / 弃牌都有飞牌动画。
- **动画**：全部走 Motion（底层是 Web Animations API，动画交给合成器），
  只动 `transform` / `opacity`，不动 `box-shadow` 这类会逐帧重绘的属性；
  座位坐标一次性读完再统一建元素，避免反复触发同步重排。
- **版本与强制刷新**：大厅底部显示版本号，点开可看离线缓存与 Service Worker 状态；
  「强制刷新」清掉离线缓存重新下载最新版，**欢乐豆和昵称不会丢**。
- **八雀牌**：中间是大牌堆 + 底池（最近 4 张弃牌），点牌堆摸牌、点底池直接拿走那张，
  摸到的牌会飞进手牌里排好序的位置；听牌按钮点开可看能胡哪些牌、各是几番；
  机会牌打出后直接进废牌堆（别人拿不走），并从牌堆最近 4 张里 4 选 1，选完还要再打一张；
  **一轮一胡**：有人胡牌或流局本轮就结束，亮出所有人的手牌，点「下一轮」继续。
- **三国牌**：选阵营时才显示该国当前的牌型倍率，选满 5 张才能出战；出战后手牌收起，
  每家先扣 5 张再从自己开始逐家翻开，每翻完一家实时刷新名次（名次与牌型标在牌上），
  底池（公共区）的牌用金色底标出，全部翻完再结算。
- **斗仙牌布阵**：点一个区域会把该区最优的牌选中在手牌上，确认后才放进去；
  上一回合飞升上来的牌带锁标记，不能移动；布阵时看不到别家的牌，三界没放满不出现「确认布阵」。
- **斗仙牌斗法**：手牌区收起，正在比拼的那一界高亮放大（牌、牌型、灵力值都放大），
  赢豆的每一家弹「胜」（可能同时 2 人赢），随后欢乐豆按比例分股飞向各赢家。
- **结算动画**：欢乐豆从输家飞向赢家，豆数滚动 + 飘字；斗仙牌还有逐区域「斗法」横幅（牌型 + 灵力值 + 名次）。
- **出牌辅助**：三国牌每个阵营直接标出「最大可做的牌型 × 倍率」，选中阵营即自动配好最大组合，也可自己点牌替换；
  斗仙牌点任一区域会自动放入该区域当前能做到的最大牌，点区域里的牌可收回替换。
- **我的资料**：随机换昵称、换头像、查看战绩；可一键重置全部数据。
- **完全离线**：无任何外部请求、无第三方脚本、无追踪。

## 数据

所有存档写在浏览器 `localStorage` 的 `sanhe_qipai_v1` 键里，只存在这台设备上。
大厅右下角「重置数据」可清空。存档键 `sanhe_qipai_v3`。
